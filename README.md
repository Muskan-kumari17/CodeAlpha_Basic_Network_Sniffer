# CodeAlpha Basic Network Sniffer

## 📌 Project Title

**Basic Network Sniffer using Python and Scapy**

This project was developed as part of the **CodeAlpha Cyber Security Internship – Task 1**.

---

## 📖 Project Overview

A network sniffer is a security and networking tool used to capture and analyze network packets travelling through a network interface.

The purpose of this project is to understand how network communication takes place and how different protocols transfer data across a network.

This project uses **Python** and the **Scapy** library to capture network packets and display useful information such as:

- Packet number
- Source IP address
- Destination IP address
- Network protocol
- Source port
- Destination port
- Available packet payload

The project provides practical experience with packet capture, IP addressing, transport-layer protocols, ports, and basic network traffic analysis.

---

## 🎯 Objectives

The main objectives of this project are:

1. To understand the basic concept of network packet capture.
2. To capture network traffic using Python.
3. To identify source and destination IP addresses.
4. To identify commonly used network protocols.
5. To identify TCP and UDP source and destination ports.
6. To inspect available packet payload information.
7. To understand the structure of network packets.
8. To gain practical knowledge of network traffic analysis.
9. To understand how packet information can be useful in cybersecurity.
10. To develop a beginner-friendly network monitoring tool.
